# Archived reference versions

These files are preserved historical sources and documentation. They are excluded from the runnable app by storing Dart sources as text. They do not describe current app behavior.

- `v11_root_main.dart.txt`: former root app, including legacy manual demo orders.
- `v13_working_main.dart.txt`: existing working scanner preserved before this fix.
- `tracked_uppercase_Main.dart.txt`: original Git content of the conflicting uppercase path.
- Other files: previous version sources, packages and documentation moved out of `lib/`.

Legacy order code has no persistent account risk ledger or reliable open-contract recovery. It must not be restored as an executable trading path without implementing and validating those requirements.
